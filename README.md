# xysey Download Manager

A desktop download manager built with Python and aria2.

## About

This project aims to build an IDM-like download manager using
aria2 as the underlying download engine.

The application communicates with aria2 through its JSON-RPC interface.

## Current Status

🚧 Early development

Currently working on:

- Starting aria2
- Connecting to aria2 through JSON-RPC
- Adding downloads
- Monitoring download progress

## Technology

- Python
- aria2
- JSON-RPC
